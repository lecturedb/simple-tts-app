# Simple TTS App

브라우저에 내장된 음성 합성 기능을 사용해 입력한 한국어 문장을 읽어 주는 간단한 Text-to-Speech(TTS) 웹 앱입니다. 별도의 서버나 외부 TTS API 없이 HTML, CSS, JavaScript만으로 실행할 수 있습니다.

## 주요 기능

- 입력한 문장을 한국어 음성(`ko-KR`)으로 읽기
- 재생 중인 음성을 즉시 중지
- 읽는 중 문장을 수정하고 **다시 읽기**를 누르면 기존 재생을 중단한 뒤 새 문장 재생
- 대기, 읽는 중, 완료, 중지 및 오류 상태 안내
- 빈 문장 입력 시 안내 메시지 표시
- 음성 합성을 지원하지 않는 브라우저에서 안내 메시지와 비활성화된 버튼 표시
- 데스크톱과 모바일 화면에 대응하는 반응형 UI

## 프로젝트 구성

```text
simple-tts-app/

├── styles.css   # 화면 스타일과 반응형 레이아웃

```

## 실행 방법

이 프로젝트는 빌드 과정이나 패키지 설치가 필요 없는 정적 웹 앱입니다.

### 로컬 서버로 실행하기

프로젝트 디렉터리에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 4173
```

그다음 Web Speech API를 지원하는 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:4173/
```

서버를 종료하려면 명령을 실행한 터미널에서 `Ctrl+C`를 누릅니다.

### 사용 방법

1. **읽을 문장** 입력란에 한국어 문장을 입력합니다.
2. **읽기** 버튼을 눌러 음성을 재생합니다.
3. 재생 중 **중지** 버튼을 누르면 현재 음성이 멈춥니다.
4. 재생 중 문장을 바꾸고 **다시 읽기** 버튼을 누르면 기존 음성이 중단되고 변경한 문장을 새로 읽습니다.
5. 화면 아래의 **현재 상태** 영역에서 재생 및 오류 상태를 확인합니다.

> 실제 음성과 발음은 운영체제와 브라우저에 설치된 음성 엔진에 따라 달라질 수 있습니다.

## 사용한 브라우저 기능

이 앱은 Web Speech API의 음성 합성 기능을 사용합니다.

- `window.speechSynthesis`: 음성 재생 요청을 관리하며 `speak()`로 재생하고 `cancel()`로 현재 재생과 대기 중인 음성을 취소합니다.
- `SpeechSynthesisUtterance`: 읽을 문장과 언어(`ko-KR`)를 담는 음성 재생 객체입니다.
- `start`, `end`, `error` 이벤트: 재생 시작, 정상 완료 및 오류를 감지해 상태 메시지와 버튼 상태를 갱신합니다.
- 기능 감지: `speechSynthesis`와 `SpeechSynthesisUtterance`의 존재 여부를 확인하고, 지원하지 않으면 안내 메시지를 표시합니다.

브라우저와 운영체제 조합에 따라 Web Speech API 지원 여부 및 제공되는 한국어 음성이 다를 수 있으므로 실제 사용할 환경에서 확인하는 것을 권장합니다.

## 테스트 방법

### 브라우저 수동 테스트

로컬 서버를 실행한 뒤 다음 항목을 순서대로 확인합니다.

1. **기본 재생**
   - 문장을 입력하고 **읽기**를 누릅니다.
   - 음성이 재생되고 상태가 `문장을 읽는 중입니다.`로 바뀌는지 확인합니다.
   - 재생이 끝나면 `읽기가 완료되었습니다.`가 표시되는지 확인합니다.
2. **중지**
   - 충분히 긴 문장을 재생한 뒤 **중지**를 누릅니다.
   - 음성이 즉시 멈추고 `읽기를 중지했습니다.`가 표시되는지 확인합니다.
3. **다시 읽기**
   - 문장을 재생하는 중 입력 내용을 다른 문장으로 바꿉니다.
   - **다시 읽기**를 누르고 기존 음성이 멈춘 뒤 새 문장이 재생되는지 확인합니다.
4. **빈 입력 예외 처리**
   - 입력란을 비운 상태에서 **읽기**를 누릅니다.
   - `읽을 문장을 입력해 주세요.`가 표시되고 입력란으로 포커스가 이동하는지 확인합니다.
5. **브라우저 미지원 처리**
   - Web Speech API를 지원하지 않거나 해당 기능을 비활성화한 환경에서 페이지를 엽니다.
   - 미지원 안내 메시지가 표시되고 읽기 및 중지 버튼이 비활성화되는지 확인합니다.
6. **반응형 화면**
   - 브라우저 개발자 도구에서 모바일 화면 크기로 전환합니다.
   - 입력란, 버튼 및 상태 영역이 화면 너비 안에서 정상적으로 표시되는지 확인합니다.

### 기본 코드 및 정적 파일 확인

JavaScript 문법을 확인합니다.

```bash
node --check app.js
```

로컬 서버를 실행한 상태에서 HTML과 JavaScript 파일이 정상적으로 제공되는지 확인할 수 있습니다.

```bash
curl --fail http://127.0.0.1:4173/
curl --fail http://127.0.0.1:4173/app.js
```

## GitHub Pages 배포

이 저장소는 GitHub Actions로 정적 사이트를 `gh-pages` 브랜치에 배포하도록 설정되어 있습니다. GitHub 저장소의 **Settings > Pages**에서 다음과 같이 설정합니다.

- Source: `Deploy from a branch`
- Branch: `gh-pages`
- Folder: `/ (root)`

`main` 브랜치에 push하면 기본 경로에 배포됩니다.

```text
https://<OWNER>.github.io/<REPO>/
```

다른 작업 브랜치에 push하면 브랜치 이름을 안전한 URL 경로로 변환한 미리보기 경로에 배포됩니다.

```text
https://<OWNER>.github.io/<REPO>/previews/<branch-slug>/
```
